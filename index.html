    A tweak tool should ask before it changes anything.

    Hi+OPTIMIZER opens with two prompts every single run — this is not optional, and it's not buried in a settings menu.

    01 · Restore point

    The first prompt on launch offers a System Restore checkpoint tagged "HI+OptimizerRestorePoint" — one keystroke to undo the whole session later.

    02 · Registry backup

    Second prompt exports HKLM, HKCU, and HKCR to C:\RegistryBackup before any module touches the registry.

    03 · Every disable, reversible

    Each "Disable" service module ships with a matching "Re‑enable" option in the same menu — nothing is a one‑way door.

    Before you run anything as Administrator

    Is this safe to run on a laptop?

    Most modules are fine. The Power Tweaks module specifically disables sleep, hibernation, and fast startup, and is flagged "not recommended for laptops" in the tool itself — skip that one on battery‑powered devices.

    What's the actual difference between Free and Paid?

    Free covers 8 core modules — CPU, GPU, RAM, Internet/Network, Latency, System/Perf, Debloat, and Wifi Fix — with the standard tweak set. Paid unlocks Disk Tweaks, Game Booster, and Power Tweaks on top, and runs a noticeably deeper pass within every module — around 10x more tweaks applied overall. It also comes with lifetime updates and a support warranty.

    Can I undo everything afterward?

    Yes — restore the System Restore checkpoint from launch, or re‑import the .reg backups from C:\RegistryBackup. Any "Disable" module also has a matching "Re‑enable" entry in the same menu.

    Does it need an internet connection?

    No — every module runs local registry, service, and power‑plan commands. Nothing is downloaded or phoned home.
